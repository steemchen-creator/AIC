# AIC Project Roadmap

## Vision

Build AIC (AI Investment Command Center) into a complete institution-grade intelligent financial terminal.

## Current stage

SPEC-009 foundation and its post-publication governance Closeout are complete.
DEV-GOV-001 is the currently authorized development-infrastructure task; it must
complete Architecture Review and Chairman manual merge before activation.
SPEC-010 remains not started. The long-term roadmap below is unchanged.

## Roadmap

```text
Project Governance
        |
       V0.1
        |
       V0.2
        |
       V0.3
        |
       V0.5
        |
       V1.0
        |
Institution Edition
```

- Project Governance: establish how the project is planned, changed, reviewed, and documented.
- V0.1: form the first governed project baseline.
- V0.2: mature the validated foundation.
- V0.3: expand the validated foundation.
- V0.5: consolidate the pre-release system.
- V1.0: establish the first stable release line.
- Institution Edition: evolve into the complete institution-grade product.

Detailed features are intentionally deferred to milestone planning.
