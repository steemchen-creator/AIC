# GitHub Labels

| Label | Use |
| --- | --- |
| `bug` | Confirmed defect or regression. |
| `feature` | New user or system capability. |
| `improvement` | Enhancement to existing behavior, quality, or process. |
| `architecture` | Architecture discussion or ADR work. |
| `database` | Data storage, schema, migration, or recovery. |
| `performance` | Latency, throughput, resource, or scalability work. |
| `security` | Security risk, control, or remediation. |
| `documentation` | Documentation-only work. |
| `question` | Clarification or investigation request. |
| `research` | Time-boxed exploration without implementation commitment. |
| `blocked` | Work awaiting a decision or dependency. |

Labels describe scope and state; they do not replace milestones or acceptance criteria.
